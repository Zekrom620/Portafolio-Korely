# Korely - Plataforma de Reclutamiento Inteligente 🚀

Bienvenido al repositorio oficial de **Korely**, desarrollado para la asignatura TPY1101.

## 📂 Estructura del Repositorio
* **01_Gestion:** Documentación administrativa y acta de constitución.
* **02_Producto:** Código fuente (Backend en FastAPI, Frontend en Next.js) y scripts de Base de Datos.
* **03_Documentacion:** Diseños técnicos, diagramas UML, casos de uso y gestión de avance.

## 🛠️ Stack Tecnológico
* **Backend:** Python (FastAPI)
* **Frontend:** Next.js
* **DB:** PostgreSQL + pgvector
* **Diseño:** Figma / Draw.io
